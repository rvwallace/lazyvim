# LazyVim configuration

Personal [LazyVim](https://www.lazyvim.org/) configuration.

Neovim loads this configuration from `~/.config/lazyvim` when it starts with
`NVIM_APPNAME=lazyvim`. See [docs/setup.md](docs/setup.md) for shell-neutral
and shell-specific startup examples.

Keep the experimental `scvim` configuration separate.
